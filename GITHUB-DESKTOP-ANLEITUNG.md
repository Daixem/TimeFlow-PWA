# TimeFlow mit GitHub Desktop sichern

Der Ordner ist bereits als Git-Repository vorbereitet und enthält den ersten
lokalen Sicherungsstand von **TimeFlow Alpha 0.3 – Sprint 2**.

## Repository in GitHub Desktop öffnen

1. GitHub Desktop starten und mit dem gewünschten GitHub-Konto anmelden.
2. Im Menü **File → Add local repository** auswählen.
3. Bei **Local path** diesen Ordner auswählen:

   `C:\Users\Stefa\OneDrive\Dokumente\TimeFlow`

4. Auf **Add repository** klicken.

## Zum ersten Mal auf GitHub hochladen

1. Oben in GitHub Desktop auf **Publish repository** klicken.
2. Als Namen beispielsweise `TimeFlow-PWA` eintragen.
3. Als Beschreibung eintragen:

   `Mobile PWA für Zeiterfassung und Dienstpläne – Alpha 0.3, Sprint 2`

4. **Keep this code private** aktiviert lassen, wenn das Projekt nicht
   öffentlich sichtbar sein soll. Für ein öffentliches Repository den Haken
   entfernen.
5. Das gewünschte GitHub-Konto beziehungsweise die Organisation auswählen.
6. Mit **Publish repository** bestätigen.

## Spätere Sicherungen

1. Nach Änderungen GitHub Desktop öffnen.
2. Links unter **Changes** die geänderten Dateien kontrollieren.
3. Unten links eine kurze Zusammenfassung eintragen, zum Beispiel
   `Sprint 3: Statistik begonnen`.
4. Auf **Commit to main** klicken.
5. Anschließend oben auf **Push origin** klicken.

Jeder Commit ist ein wiederherstellbarer Sicherungspunkt. Mit
**History** können ältere Stände angezeigt werden.
